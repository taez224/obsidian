# 🗺 지식관리와 글쓰기

생각을 그냥 쌓아두지 않고, 다시 찾아 쓸 수 있는 노트로 다듬어 글과 공개된 지식으로 이어 가는 방식을 모은 허브다.

## 제텔카스텐

- [[제텔카스텐은 상향식으로 글감을 성장시키는 시스템이다]] - 작은 생각을 연결해 글감으로 키우는 전체 흐름
- [[포착과 영구 노트 승격은 분리해야 한다]] - 빠른 기록과 의미 판단을 분리하는 운영 경계

## 연결하고 다시 찾기

- [[노트는 작성할 때 다시 찾을 상황까지 고려해야 한다]] - 미래의 조회 맥락까지 생각하는 노트 작성
- [[세컨드 브레인은 퍼스트 브레인의 사고를 보조해야 한다]] - 도구를 활용하되 이해와 채택의 책임을 남기는 원칙

## 생각을 글로 다듬기

- [[템플릿은 내용을 채우는 틀이 아니라 생각을 확장하는 질문이어야 한다]] - 형식보다 질문으로 생각을 확장하는 템플릿
- [[초안을 완성도로 검열하면 발산이 일찍 끝난다]] - 발산과 수렴을 분리하는 초안 작성 원칙

## 공개하고 가꾸기

- [[위키 가드닝 규칙]] - 공개 위키의 운영 원칙과 변경 이력
