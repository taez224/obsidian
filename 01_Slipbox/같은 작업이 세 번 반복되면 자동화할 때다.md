# 같은 작업이 세 번 반복되면 자동화할 때다

자동화의 타이밍은 예측이 아니라 반복 횟수로 정한다. 같은 작업을 한 번 했을 때 만드는 자동화는 추측이고, 세 번 반복된 마찰을 올리는 자동화는 검증된 투자다. 반대 방향도 성립한다 — 아직 반복되지 않은 1회성 실무를 예방적으로 규칙·스킬로 만들면 유지보수 부담만 남는다.

## 설명과 예시

e2e 검증 스크립트를 처음 손으로 실행하고, 다음 날 반복 실행하면서 정리하고, 반복이 확실해진 시점에 슬래시 커맨드로 승격한 3단계 진화가 전형이다. 반복이 자동화보다 먼저 와야 자동화가 실제 사용 형태에 맞게 만들어진다.

이 원칙은 개인 지식관리 시스템 운영에도 그대로 적용 중이다 — 새 스킬·워크플로·베이스는 같은 마찰을 3번 겪은 뒤에만 만든다.
