# 기존 Web Clipper 보관본 정리

사용자가 기존 Clipping 정리를 승인했을 때만 적용한다.

1. 기존 `title`, `source`, 저자·발행일, `status`, `my_take`, 사용자 메모를 보존한다.
2. 확인 가능한 한국어 `description`과 내용 요약 4~7개를 카드에 둔다. 확인이 부족하면 요약을 생략한다.
3. 본문의 중복 `## 원문` 링크를 제거한다.
4. 전문이나 장문 번역이 있으면 사용자의 로컬 보관 의사를 확인한다.
5. 보관하기로 했다면 `local-snapshot.md`를 읽고 `_local-snapshots/`에 먼저 복사해 검증한 뒤 추적 카드에서 제거한다.
6. 전문 제거만 요청했거나 로컬 보관을 원하지 않으면 체크포인트 또는 복구 가능한 Git 상태를 확인한 뒤 제거한다.

이 절차는 카드의 의미를 다시 쓰는 작업이 아니다. 사용자의 `my_take`나 읽기 상태를 임의로 바꾸지 않는다.
