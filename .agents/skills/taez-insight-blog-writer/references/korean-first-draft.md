# 한국어 초안 점검

새 글의 첫 문장을 쓰기 전과, 구조를 확정한 직후의 짧은 자체 점검에만 사용한다. 목적은 휴머나이저가 사후에 고칠 표현을 처음부터 줄이는 것이지, 문장을 인위적으로 꾸미는 것이 아니다.

## 쓸 때 지킬 것

- 추상 주어 대신 사람이 한 행동, 실제 도구, 실제 문서, 실제 비용을 주어로 둔다.
- 한 문단에는 장면·원인·판단·예시 중 한 가지 일을 우선 맡긴다.
- 목록은 실제 절차·비교·선택지를 보여줄 때만 쓴다. 문장을 조각내기 위한 목록은 만들지 않는다.
- 인용·수치·고유명사·기술 약어는 원문 그대로 둔다.

## 피할 표현 습관

- 영어식 번역투: `~에 대해`, `~를 통해`, `~에 있어서`, `~와 관련하여`, `~에 의해`, 긴 관형어를 문맥에 맞는 조사·능동형·짧은 문장으로 바꾼다.
- 내용 없는 안내와 결산: `주목할 점은`, `중요한 것은`, `본질적으로`, `결론적으로`, `정리하면`을 쓰기 전에 그 뒤의 주장만으로 문단이 서는지 확인한다.
- 정형 전환: `먼저-반면-결국`, `X가 아니라 Y`, `~해야 할 때다`를 반복하지 않는다. 실제 비용·변화·판단을 바로 쓴다.
- 추상 명사 연쇄와 만능 동사: `전략적/본질적/효율성` 같은 명사 묶음, `수행·진행·가지다·보여주다`는 구체 동사나 문장으로 푼다.
- 리듬 자동화: 같은 문장 길이, 같은 종결어미, 문두 접속사의 연속을 줄인다. 자연스러운 문장을 억지로 다양하게 만들지는 않는다.

## 30초 자체 점검

1. 각 문단의 첫 문장이 주장이나 사실을 바로 말하는가?
2. 빼도 의미가 같은 안내 문장·강조 부사가 남아 있지 않은가?
3. 문장을 매끄럽게 하려다 원문에 없던 비유·감정·주장을 보태지 않았는가?
4. 설명이 필요한 기술 용어만 남기고, 영어 병기와 괄호를 반복하지 않았는가?

이 점검 뒤에도 번역투나 정형 문장이 눈에 띄면 `humanize-korean`을 별도 요청으로 실행한다. 전체 휴머나이즈는 의미 보존이 더 중요한 발행 직전이나 사용자가 명시적으로 요청한 경우에만 쓴다.
