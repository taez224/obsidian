## 내용 요약

- React Router 7은 핵심 기능을 `react-router` 패키지로 통합하면서 기존 `react-router-dom`과 버전 6 애플리케이션의 점진적 전환 경로를 제공한다.
- 라이브러리 모드에서는 `json()` 유틸리티가 제거되고 `defer` 사용 방식이 단순해지는 등 데이터 로딩 API가 조정된다.
- 프레임워크 모드는 서버 사이드 렌더링, 파일 기반 라우팅과 코드 분할을 결합해 풀스택 React 애플리케이션 구성을 지원한다.
- loader·action, 중첩 레이아웃, React의 `Suspense`, 타입 안전성 등 라우팅과 데이터 처리의 주요 개선점을 예제로 설명한다.
- 버전 6 또는 Remix 프로젝트에서 패키지와 import를 바꾸고 데이터 로딩·서버 로직을 검증하는 마이그레이션 절차를 제시한다.
