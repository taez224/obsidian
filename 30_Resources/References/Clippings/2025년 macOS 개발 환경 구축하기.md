## 내용 요약

- Xcode Command Line Tools와 Homebrew를 먼저 설치해 macOS 개발 환경의 기본 도구와 패키지 관리 기반을 마련한다.
- 기본 터미널·iTerm2·Warp를 비교하고 `ripgrep`, `fzf`, `jq`, `zoxide` 같은 CLI 도구와 zsh 환경을 구성한다.
- VS Code, Docker Desktop·Colima, `nvm`·`pyenv`·`rbenv`를 이용해 편집기·컨테이너·언어별 버전을 관리한다.
- 데이터베이스, 원격 접속, 클립보드, 시스템 모니터링, 창 관리, Git과 비밀정보 검사 도구까지 일상 개발에 필요한 앱을 정리한다.
- Keyboard Maestro로 작업 환경 실행과 창 배치 등을 자동화하고 Homebrew·Docker·다운로드 폴더를 주기적으로 정리하는 흐름을 소개한다.
