## 내용 요약

- 모듈화·추상화·계층화부터 확장성·보안·장애 허용까지 시스템 설계의 기본 원칙을 훑는다.
- DNS, 로드 밸런서, API 게이트웨이, CDN, 메시지 큐, 캐시, 데이터베이스, 복제와 분산 ID 같은 주요 구성 요소를 설명한다.
- 서명된 URL과 청크 업로드를 조합해 대용량 이미지와 동영상을 처리하는 흐름을 다룬다.
- RTMP, WebRTC, WebSocket, SSE, 폴링, Webhook 등 실시간 통신 방식을 비교한다.
- 결제·분석·알림·검색·추천 서비스와 요구사항 수집부터 검증까지의 설계 절차를 정리한다.
