# 정적 사이트의 OG 카드를 빌드 때 만들고 Umami로 방문을 센다

링크를 메신저나 SNS에 붙이면 `og:image`가 카드 그림으로 뜬다. 사이트 전체가 그림 한 장을 쓰면 어떤 글을 공유해도 카드가 같다. 글마다 제목이 들어간 카드를 만들되, 서버 없이 빌드 산출물로 끝내는 구성을 정리한다. 방문 통계도 같은 원칙(서버 없음, 쿠키 없음)으로 붙인다.

## OG 카드를 빌드 때 만든다

### 구성

1. **SVG 문자열을 직접 만든다.** 1200×630 캔버스에 배경, 워드마크, 제목, 메타 줄, 장식을 `<text>`·`<circle>`·`<line>`으로 쓴다. 템플릿 엔진이 필요 없고, 글자 위치를 픽셀로 제어할 수 있다.
2. **`@resvg/resvg-js`로 PNG로 굽는다.** SVG를 PNG로 바꾸는 네이티브 모듈이다. 브라우저·헤드리스 크롬이 필요 없고 GitHub Actions에서도 그대로 돈다. OG 이미지는 대부분의 플랫폼이 SVG를 받지 않으므로 PNG가 필요하다.
3. **Astro 정적 엔드포인트로 노출한다.** `src/pages/og/[...slug].png.ts`에서 `getStaticPaths`로 노트마다 경로를 만들고 `GET`이 PNG 버퍼를 돌려주면 빌드 때 `dist/og/<종류>/<슬러그>.png`가 생긴다. 페이지 레이아웃은 자기 카드 주소를 `og:image`에 넣는다. 노트가 아닌 페이지(홈·목록)는 사이트 카드 한 장을 쓴다.

### 폰트

resvg는 시스템 폰트를 쓰지 않도록 두고 TTF/OTF 파일을 직접 넘긴다. CI 이미지에 한글 폰트가 없기 때문이다. woff2는 받지 않으므로 정적 OTF가 필요하다.

- 명조 제목: Noto CJK 저장소의 한국어 서브셋 정적 OTF(`NotoSerifKR-Bold.otf`, 약 8MB).
- 고딕 메타: Pretendard 저장소의 정적 OTF(`Pretendard-Medium.otf`).
- 저장소에 넣기엔 커서 **첫 빌드 때 내려받아 `node_modules/.cache`에 둔다.** 실패하면 경고를 내고 시스템 폰트로 대신 그려 빌드는 멈추지 않는다. 캐시 경로는 번들된 모듈 위치가 아니라 프로젝트 루트 기준으로 잡아야 한다(처음엔 `import.meta.url` 기준으로 잡아 `dist/` 안에 폰트가 들어갔다).
- 가변 폰트 대신 정적 인스턴스를 골랐다. resvg가 가변 폰트의 굵기 축을 어떻게 고르는지 확인하지 않아서다.

### 제목과 장식

- 제목은 세 줄 안에 들어가는 가장 큰 크기(60→54→48→42→36px)를 고르고, 그래도 넘치면 마지막 줄을 줄임표로 자른다. 글자 폭은 한글 12.5·영숫자 7.2·그 외 4.5px(13px 기준)로 어림한다. 실제 폰트 측정 없이도 카드에서는 충분했다.
- 오른쪽에는 그 노트의 로컬 그래프(중심 노드 + 이웃 최대 8개)를 주제 색으로 얹는다. 같은 템플릿인데 글마다 모양이 달라진다. 사이트 카드에는 전체 지도를 얹는다. 배치 원리는 [[그래프의 노드 제목이 겹치지 않게 놓는 방법]]과 같은 코드를 쓴다.
- 워드마크가 왼쪽 위에 있으면 제목에 이름을 다시 넣지 않는다. 카드 안에서 같은 이름이 두 번 보이면 눈이 두 번 걸린다.

### 검증

- 노트 91편 기준 카드 3.4MB, 빌드 시간 약 6초 증가.
- 빌드 검사 스크립트가 `site.json`의 노트마다 카드 파일이 있는지 확인한다.
- 배포 뒤 카드 URL이 `image/png` 200으로 열리고 페이지의 `og:image`가 그 주소인지 확인했다. 이미 공유했던 링크는 플랫폼 캐시 때문에 한동안 옛 이미지가 보인다.

## Umami Cloud로 방문을 센다

GitHub Pages는 서버 로그가 없다. 쿠키 없이 방문을 세는 도구 중 Umami Cloud를 골랐다. 2026-09-06 요금 페이지 기준 Hobby 플랜은 무료이고 월 10만 이벤트(페이지뷰 1회 = 1이벤트), 웹사이트 1개, 보관 6개월이다. 대시보드는 본인만 본다.

- 스크립트는 사이트 설정 파일(`config.json`의 `analytics.umami`)에서 읽어 헤더에 넣는다. ID가 비어 있으면 아무것도 넣지 않는다.
- `data-domains="taez224.github.io"`를 붙이면 로컬 미리보기·프리뷰 배포에서는 집계되지 않는다.
- **본인 방문 제외**는 IP가 아니라 브라우저 저장소 값으로 한다. Umami 스크립트는 보내기 직전에 `localStorage`의 `umami.disabled`를 읽는다. 기기·브라우저마다 한 번씩 값을 심어야 하므로, 주소에 `?stats=off`를 붙여 열면 값을 심고 화면 위에 "이 브라우저의 방문은 통계에서 제외됩니다"를 한 줄 띄우는 인라인 스크립트를 뒀다(`?stats=on`으로 되돌림). 인라인 스크립트는 파싱 중 바로 실행되고 Umami 스크립트는 `defer`라 그 뒤에 실행된다.
- 설정을 방금 배포한 직후에는 페이지 캐시(10분) 때문에 이전 HTML을 받을 수 있다. 제외가 안 되는 것처럼 보이면 확인 문구가 뜨는지 먼저 본다.
