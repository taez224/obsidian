## 학습 & 인사이트

- **ADR의 무게는 reference 문서에 있다**: ADR-019 검토가 본문보다 reference 2개(`presyncjob-best-practices`, `subscription-secret-input-design`)를 같이 봤을 때 비로소 "시나리오 판정 가능"으로 진전. 본문만 보면 결정이 안 닫힘.
- **dogfooding은 시간차 회로**: vizend-agent-hub에서 12일 marketplace 등록 → 13일 다른 레포에서 호출 → 14일 신규 스킬 추가의 사이클. **자기 도구를 자기가 쓸 때 도구의 결함이 가장 빨리 드러난다** (UP-TO-DATE 반복 이슈, /review-implement frontmatter 실패 등).
- **DevLog ≠ 주간보고**: 05-15 "PM이 이해할 수 있게 정리" 요청 — DevLog는 *시간 흐름의 기록*, 주간보고는 *결과 중심의 압축*. 같은 데이터에서 두 산출물이 나와야 함을 의식적으로 분리.
- **로컬 plugin marketplace의 가치**: GitLab push 없이 로컬 경로 그대로 marketplace 등록 가능 → **빠른 반복 사이클이 핵심**. 외부 시스템(GitLab CI 등)에 의존하지 않고 즉시 테스트 가능한 환경이 dogfooding의 필수 조건.
- **Claude Code Desktop의 새로운 워크플로우**: 데스크탑 앱에서 개발서버 미리보기 + AI 작업 동시 진행은 모바일·CLI에서 불가능한 작업 양식. 도구가 늘면 작업 양식 자체가 갈라짐.
- **회귀적 발견**: 05-13에 `kepano/obsidian-skills` 등록 → 그 이후로 이 vault에서 obsidian-markdown 등 스킬 사용 가능. **이 DevLog가 작성되는 환경 자체도 W20의 결정에 의존**한다는 메타적 사실.
