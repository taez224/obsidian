# 2026-03-19 DevLog

## vizend-qra-backend

### Pod 모니터링 정보 확장 및 배포 관측 개선 (#54)

- 구독 서비스 Pod 상태/리소스 조회 기능 구현 (US-9.1)
- Metrics Server 가용 시 Pod별 CPU/Memory 사용량 반환, 미가용 시 graceful degradation
- 리뷰 피드백 반영: 역방향 의존 해소, enum 활용 리팩토링

### 배포 준비 실패 시 batch 즉시 실패 기록 (#182)

- `resolveImageRefs` / `prepare` 실패 시 deployable 타겟 결과를 batch에 즉시 실패로 기록
- Gallery로 실패 통지 정상 발행 보장
- 타임라인에 실패 Stage 기록, 예외 재던지기 방지(무한 재시도 차단)

### Namespace 단위 shared informer/cache 구조로 재편 (#178)

- K8sPodWatcher가 watch마다 개별 informer 생성 → namespace 단위 shared informer 공유로 전환
- K8sPodStatusProxy의 live `list()` 호출을 shared informer cache 기반 조회로 변경
- ArgoCdObservationTask, RuntimeMonitoringSeek의 Pod 상태 조회도 cache-backed read로 전환
- leader-only 원칙(ADR-015) 및 멱등 수렴 모델(ADR-016) 유지

### Kubernetes client 설정 속성 추가 (#181)

- K8s client configuration properties 구조화

### K8S Event on-demand enrichment (#184, #185)

- `K8sEventQuery` proxy 신규 구현: namespace + pod 기준 K8S Warning Event 조회 (uid 우선, name fallback)
- `FailureMessageEnricher` 신규 구현: K8S Event 기반 실패 메시지 보강
- `ArgoCdObservationTask` 실패 경로에서 enricher 연동
- 조회 실패 시 기존 메시지 유지 (graceful degradation)

### 의존성 및 문서

- `accentVersion` 7.1.10, `prologueVersion` 7.1.29로 업데이트
- K8S cluster monitoring 구독 및 SSE 프론트엔드 가이드 문서 추가
