# _workspace 임시 작업 산출물

블로그 검토·자료 조사·스킬 행동 평가 등이 남기는 임시 작업 폴더다. 작업과 실행일을 알아볼 수 있는 이름을 쓴다. `YYYY-MM-DD-NNN/`, `작업명-YYYY-MM-DD/`처럼 여러 형식을 사용할 수 있으며, 기존 폴더를 이름 때문에 바꾸지는 않는다.

이 폴더는 `.gitignore` 대상이다. 이미 Git으로 추적하는 이 README를 제외한 새 산출물은 기본적으로 커밋되지 않으므로, 삭제한 파일을 Git에서 복구할 수 있다고 가정하지 않는다. 원자료·실행 조건이 없으면 다시 만들 수 없는 결과도 있다.

## 수명 정책

- **7일 이내**: 재검토·디버깅을 위해 유지한다.
- **7일 경과**: 정리 후보로 본다. 진행 중인 작업에서 쓰는지, 다시 만들 수 있는지, 보존할 근거가 있는지 확인한다.
- 계속 사용할 판단·근거는 승인된 범위에서 적절한 정본으로 옮기거나 별도로 보존한 뒤 정리한다. 이 폴더를 장기 보관소로 쓰지 않는다.
- 삭제는 대상과 보존 필요를 확인하고 사용자 승인 후 수행한다. 나이나 폴더 이름만으로 자동 삭제하지 않는다.

## 정리 후보 확인

이름 형식과 관계없이 폴더의 수정 시각이 7일 넘게 지난 후보를 나열한다. 삭제는 실행하지 않는다.

```bash
find _workspace -mindepth 1 -maxdepth 1 -type d -mtime +7 -print
```

폴더 자체의 수정 시각만 보는 목록이다. 하위 파일의 최근 변경이나 현재 작업의 사용 여부까지 확인한 뒤 삭제 대상을 정한다. vault 커밋만으로 Git에서 제외된 산출물이 보존되지는 않는다.
