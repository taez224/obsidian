# Jotai tutorial

## 연재 목적

Jotai의 원자적 상태 관리 방식을 작은 예제부터 복합 상태 구성까지 단계적으로 익힌다.

## 현재 상태

Velog에 7편을 발행한 완결 튜토리얼이다. 2023년 당시의 Jotai 버전과 학습 맥락을 보존하며, 최신화가 필요하면 기존 글을 무리하게 고치기보다 현재 버전과 달라진 점을 별도 글로 다룬다.

## 연재 흐름

1. [[Jotai 01 - Tutorial의 Tutorial]] - Jotai와 원자적 상태 관리의 출발점을 소개한다.
2. [[Jotai 02 - My first atom]] - 첫 atom을 만들고 사용하는 기본 흐름을 다룬다.
3. [[Jotai 03 - Derived atom Read Only]] - 파생된 읽기 전용 atom을 설명한다.
4. [[Jotai 04 - Write Only atom]] - 쓰기 동작을 분리한 atom을 다룬다.
5. [[Jotai 05 - Read Write atom]] - 읽기와 쓰기를 함께 가진 atom을 구성한다.
6. [[Jotai 06 - atom 구조화]] - atom과 상태 구조를 확장한다.
7. [[Jotai 07 - atoms in atom]] - 여러 atom을 하나의 atom 안에서 다루는 패턴으로 마무리한다.

## 확장 기준

- 기존 글은 당시 버전의 학습 기록으로 보존한다.
- 새로운 글은 최신 Jotai의 변화나 실제 프로젝트 적용처럼 기존 연재에 없던 가치가 있을 때만 추가한다.

## 운영 메모

- 실제 발행 상태와 순서는 각 글의 frontmatter를 정본으로 삼는다.
- 이 노트는 튜토리얼의 학습 순서와 버전 경계를 보존한다.
