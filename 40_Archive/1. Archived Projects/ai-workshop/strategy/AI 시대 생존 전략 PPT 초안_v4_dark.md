## 3. 인간^AI: 역량의 증폭

### 슬라이드 제목
```
인간^AI: 역량의 증폭
```

### 상단 메시지
```
AI는 평등화 도구가 아니라 격차를 키우는 증폭기다
```

### 시각 자료 아이디어
- ‘기본 역량’과 ‘AI 활용도’ 게이지를 곱하는 인포그래픽으로 공식 시각화
- 0.7/1.0/1.2 세 가지 성과 지표를 삼색 막대로 비교
- 숙련 팀 vs 초급 팀 사례를 2열 카드로 배치해 대비감 강조

### 핵심 공식 (상단 강조)
```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│            결과물 = 기본역량^AI활용도                  │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 역량 격차의 현실

```
기본 역량 70%인 개발자:  0.7³ = 0.34 (성과 -66%)
기본 역량 100%인 개발자: 1.0³ = 1.0 (기준)
기본 역량 120%인 개발자: 1.2³ = 1.73 (성과 +73%)

→ 출발선 50% 격차가 결과물 4배 차이로
```

### 실제 사례 & 경고
```
• Copilot 숙련 팀: 배포 시간 3배 단축 (GitHub, 2023)
• Copilot 초급 팀: 디버깅 시간 2배 증가 
→ 프롬프트 의존만으로는 품질이 오히려 저하될 수 있다
```

### 하단 핵심 메시지
```
⚡ AI는 증폭기: 탁월함도 미숙함도 모두 증폭한다
```

```
🤝 협업과 소통 능력

• 공감 기반 대화로 갈등을 에너지로 전환
• 신뢰와 동기부여를 통해 실행 속도를 끌어올림

→ 맥락 읽기와 감정 교류는 여전히 인간의 영역
```

```
AI 협력자로의 진화
```

### 상단 메시지


### 시각 자료 아이디어
- 사람과 AI가 함께 일하는 일러스트
- “질문→피드백→재질문” 흐름을 보여주는 순환 도식

### 레이아웃: 3개 카드

#### 카드 1: AI 리터러시
```
🎯 AI 리터러시

진짜 경쟁 상대는 AI가 아니라
AI를 민첩하게 활용하는 다른 사람들이다

→ 개인부터 경영진까지 필수 역량으로
```

#### 카드 2: 팀원 관점
```
🤝 팀원 관점

AI를 지적 협력자로 대우하라
• 문제 정의 → 초안 생성 → 맥락 피드백
• 결과 검토 → 방향 재설정 → 추가 요청

→ 명령이 아닌 대화가 품질을 높인다
```

```
🔄 반복 개선

완벽은 반복 학습에서 완성된다
• AI 출력 검증 → 개선점 피드백 → 재요청
• 검증 기록을 축적해 다음 시도를 가속

→ 순환이 쌓일수록 품질과 속도가 동시에 오른다
```

## 9. AI 활용 레벨: 언더퍼포머 vs 아웃퍼포머

### 슬라이드 제목
```
언더퍼포머 vs 아웃퍼포머
```

### 레이아웃: Split Screen 비교

### 시각 자료 아이디어
- 좌/우 대비 그래픽(언더퍼포머 vs 아웃퍼포머)
- 도구 아이콘을 나열한 하단 바(코드/분석/검색/창작)

#### [좌측] 언더퍼포머 (❌)
```
🔻 언더퍼포머

AI를 단순 검색 엔진으로 취급

• 질문을 던지고 답만 기다린다
• 출력물을 검증 없이 그대로 사용한다
• 기대에 미치지 못하면 시도를 멈춘다
• 도구 자체가 목적이 된다

→ 활용 역량이 한계에 묶여 있다
```

#### [우측] 아웃퍼포머 (✅)
```
🔺 아웃퍼포머

AI를 지적 파트너로 설계

• 함께 문제를 정의하고 가설을 만든다
• 출력물을 비판적으로 검토하고 보완한다
• 피드백과 코칭을 통해 역량을 확장한다
• 반복적 개선으로 업무 속도를 끌어올린다

→ 활용 잠재력이 기하급수적으로 확장된다
```

### 하단 메시지

```
⚡ 도구 선택도 전략이다

코드: Cursor, Copilot  |  분석: Claude, ChatGPT  |  검색: Perplexity  |  시각화: GenSpark

→ 목적에 맞춰 도구를 조합하고 전환하는 능력이 경쟁력이다
```

## 14. Human-in-the-Loop 운영 모델

### 슬라이드 제목
```
Human-in-the-Loop 운영 모델
```

### 상단 메시지
```
AI 제안·검증·학습을 하나의 순환으로 묶어야 성숙한 운영이 가능하다
```

### 시각 자료 아이디어
- 사람↔AI 순환 다이어그램
- 단계별 책임자와 산출물을 보여주는 캔버스
- 오류 로그 → 개선 → 재학습 흐름을 나타내는 정적 플로우 차트

### 3단계 순환
1. **인간 입력**: 기준·정책 정의, 맥락 제공 (예: MS Copilot 파일럿팀의 ‘AI 브리핑 문서’)
2. **AI 처리**: 데이터 분석·패턴 탐지, 자동 제안 (분석·요약·코드 생성)
3. **인간 검토 & 학습**: 결과 검증, 예외 처리, 재학습 지시 (오류 기록 후 모델 개선)

### 역할 분담 예시
- Step 1: 리더·도메인 오너가 목표와 가드레일 설계
- Step 2: AI 에이전트·자동화 파이프라인이 처리 수행
- Step 3: QA/운영팀이 검증하고 학습 로그를 축적

### 문화 적용 포인트
- 주간 AI 리뷰 미팅으로 성공·실패 사례를 공유
- AI 출력 검증 체크리스트를 운영하고 실패도 데이터로 저장

### 하단 메시지
```
Human-in-the-Loop는 리스크 방어가 아니라 역량 증폭 장치다. 기록과 학습이 쌓일수록 AI는 더 똑똑해진다.
```

### 하단 메시지


## 16. 리더십 2.0 - AI 해석자·조력자


### 시각 자료 아이디어
- 과거 vs AI 시대 리더십 비교 테이블
- 4개 역할 아이콘(해석자/공감자/실험 촉진자/가드레일 설계자)

### 과거 vs AI 시대 리더십 비교
```
┌────────────────────┬────────────────────────────┐
│   과거 리더십       │   AI 시대 리더십             │
├────────────────────┼────────────────────────────┤
│ 지시·통제 중심     │ 데이터 기반 코칭·조력       │
│ 계획-보고-승인 순환 │ 실험-검증-확장 순환         │
│ 정보 비대칭         │ 데이터·가드레일 투명 공유   │
│ 위험 회피           │ 실패 로그를 학습 자산으로   │
│ 역할 고정           │ 역할·리더십이 유동적으로 순환│
└────────────────────┴────────────────────────────┘
```

### 4가지 역할과 핵심 질문
1. **데이터 해석자** — *“이번 주 팀이 알아야 할 인사이트는 무엇인가?”*
   • AI 리포트와 운영 지표를 연결해 의미를 해석하고 우선순위를 재조정

2. **공감 커뮤니케이터** — *“구성원이 불안해하는 지점은 어디이며 나는 어떻게 지원할 수 있는가?”*
   • 도입 과정의 불안을 경청하고 맥락을 공유해 신뢰를 촉진

3. **실험 촉진자** — *“바로 테스트해 볼 아이디어는 무엇이며, 결과는 언제 확인할 것인가?”*
   • 부담 없는 실험을 신속히 돌리고, 결과를 팀과 나눠 다음 시도를 빠르게 준비

4. **가드레일 설계자** — *“AI 활용에 대한 안전선과 윤리 기준은 충분히 마련되었는가?”*
   • 정책·검증 체크리스트를 정기적으로 점검하고 리스크를 선제 관리

### 실행 루틴 제안
```
주간 AI 브리핑 → AMA·피드백 세션 → 실험 로드맵·가드레일 점검 → 성과·학습 공유
```

### 하단 메시지
```
데이터를 해석하고 공감으로 연결하며 실험과 가드레일을 동시에 챙기는 리더가 AX 정착 속도를 좌우한다.
```

```
AI 활용 오픈북 과제 루브릭, 협업 태도 관찰 체크리스트, 채용 후 90일 코칭 항목
```
